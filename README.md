# Kelly's Giraffe Getaway

A free retro side-scrolling platformer from Kelly's Arcade / Peter's Arcade.
Cackles the Hyena King captured Gigi the giraffe! Kelly walks Level 1 on foot, frees Ginny (a green giraffe with pink polka dots), then rides her through 8 more levels: neck RAM (aimable), neck-bite SWING from hooks and ledges, tongue snacks, and green gems.

Play: https://ploug76.github.io/kellys-giraffe-getaway/
